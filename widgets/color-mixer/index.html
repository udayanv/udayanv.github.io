Color conversion

How the modes connect

Every mode describes a color with three numbers. The mixer uses RGB as the bridge between them.

RYB ↔ RGB ↔ HVC

RGB

Red, green, and blue light directly set the screen color.

RYB

Red, yellow, and blue act like paint amounts. The mixer finds an approximate RGB match because screens use light, not paint. Going from RGB to RYB, it removes shared white, turns red-and-green overlap into yellow, represents remaining green with yellow and blue, rescales the result, then restores the white.

HVC

Hue chooses the color family, Value controls brightness, and Chroma controls color strength. Chroma cannot be higher than Value.

When you switch modes, the preview stays the same and the controls show the closest equivalent values.

Conversion math

First, write the RGB channels as r, g, b ∈ [0, 1].

  • V = max(r, g, b)
  • C = V − min(r, g, b), so 0 ≤ C ≤ V

Hue uses six 60-degree sections of the color wheel:

  • H = 0 when C = 0
  • H = 60 × (((g − b) / C) mod 6) when red is largest
  • H = 60 × ((b − r) / C + 2) when green is largest
  • H = 60 × ((r − g) / C + 4) when blue is largest

To return to RGB, the mixer selects the matching 60-degree hue section and adds V − C to each channel.

RYB has no equally compact formula. Its step-by-step conversion is nonlinear, which is why it behaves more like a paint-style approximation than an exact physical pigment model.
